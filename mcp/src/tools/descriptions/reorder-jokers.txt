Reorders the Jokers in the player's Joker area to the explicit left-to-right order specified by an array of Joker card IDs, where the first ID becomes the leftmost Joker and the last ID becomes the rightmost. Jokers resolve from left to right, so order can change the score: place additive Chips/Mult effects before multiplicative Mult effects unless a specific Joker interaction requires another order, and position copy Jokers such as Blueprint or Brainstorm deliberately. This action consumes no game resources. Requires a stable Joker-management phase and an order array containing exactly the current Joker IDs.
