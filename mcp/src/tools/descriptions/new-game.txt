Starts a new run with explicit settings, equivalent to the New Run setup screen. For a normal run, pass `deck` (a b_* key) and `stake` (1-8) together; optionally pass `seed` for a seeded run. For a challenge run, pass `challenge` (a c_*_1 id) alone; it cannot be combined with `deck`, `stake`, or `seed`. See the balatro://decks and balatro://challenges resources for valid values. Unlocked-only: locked decks, stakes, or challenges are rejected. Requires the game to be ready (menu or an active run); this is irreversible.
