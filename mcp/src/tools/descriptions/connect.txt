Connect to the running Balatro game. Required before any live-play tool or resource: balatro:// reads, blinds, hands, shop, packs, and run actions stay hidden until the bridge is attached. Fails INSTANCE_BUSY when another client already holds the game, GAME_NOT_RUNNING when Balatro is unreachable, PROTOCOL_MISMATCH when the mod is outdated. Safe to call again while connected: it re-verifies the session and returns the current phase.
