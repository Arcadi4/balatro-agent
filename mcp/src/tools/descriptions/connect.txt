Discover and connect to a running Balatro instance. Read balatro://instances first when more than one instance may be running. Pass the selected instance_id explicitly when multiple instances are available. Live resources and actions remain instance-scoped. Fails GAME_NOT_RUNNING when no instance is reachable, GAME_NOT_FOUND when the requested instance disappeared, INSTANCE_SELECTION_REQUIRED when selection is required, and PROTOCOL_MISMATCH when the mod is outdated. Safe to call again for the same instance: it re-verifies the session and returns the current phase.
