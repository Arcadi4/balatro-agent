Reorders the cards in the player's hand to the explicit order specified by an array of card IDs, where the first ID becomes the leftmost card and the last ID becomes the rightmost. This is a visual/organizational action that does not consume any game resources (hands or discards) and does not alter card values, ranks, suits, or any gameplay-relevant state beyond display order. Use this to reorganize cards for better visibility before deciding what to play. Requires SELECTING_HAND and an order array matching the current hand contents.
