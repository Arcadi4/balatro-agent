# Balatro Challenges Reference

Each `id` below is the value to pass as the `challenge` argument to `balatro_new_game`. A challenge run always uses White Stake, so `challenge` cannot be combined with `deck`, `stake`, or `seed`. Fetch the full wiki article for a challenge as `balatro://wiki/<Name>` with underscores for spaces, e.g. `balatro://wiki/On_a_Knife's_Edge`.

| #  | id                   | Name              | Rules                                                                                                                                         |
| -- | -------------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 1  | `c_omelette_1`       | The Omelette      | Blinds give no reward money, no interest; start with 5x Egg                                                                                   |
| 2  | `c_city_1`           | 15 Minute City    | Two copies of every face card, no Aces/2s/3s; Eternal Ride the Bus + Shortcut                                                                 |
| 3  | `c_rich_1`           | Rich get Richer   | Chips cannot exceed current money; start with $100                                                                                            |
| 4  | `c_knife_1`          | On a Knife's Edge | Eternal, Pinned Ceremonial Dagger                                                                                                             |
| 5  | `c_xray_1`           | X-ray Vision      | 1 in 4 cards are drawn face down                                                                                                              |
| 6  | `c_mad_world_1`      | Mad World         | No interest; Eternal Negative Pareidolia + Business Card; ranks 2-9 only                                                                      |
| 7  | `c_luxury_1`         | Luxury Tax        | -1 hand size per $5 held; 10 hand size                                                                                                        |
| 8  | `c_non_perishable_1` | Non-Perishable    | All Jokers are Eternal                                                                                                                        |
| 9  | `c_medusa_1`         | Medusa            | Face cards replaced by Stone cards; Eternal Marble Joker                                                                                      |
| 10 | `c_double_nothing_1` | Double or Nothing | Played cards become debuffed after scoring; all cards Red Seal                                                                                |
| 11 | `c_typecast_1`       | Typecast          | After Ante 4 Boss: all Jokers Eternal, Joker slots 0                                                                                          |
| 12 | `c_inflation_1`      | Inflation         | Prices rise $1 on every purchase; start with Credit Card                                                                                      |
| 13 | `c_bram_poker_1`     | Bram Poker        | Jokers never appear in the shop; start with an Eternal Vampire, the Tarots The Emperor + The Empress, and the Magic Trick + Illusion vouchers |
| 14 | `c_fragile_1`        | Fragile           | All cards Glass; 2x Eternal Negative Oops! All 6s                                                                                             |
| 15 | `c_monolith_1`       | Monolith          | Eternal Obelisk + Negative Marble Joker                                                                                                       |
| 16 | `c_blast_off_1`      | Blast Off         | 2 hands, 2 discards, 4 Joker slots; Eternal Constellation + Rocket                                                                            |
| 17 | `c_five_card_1`      | Five-Card Draw    | 6 discards, 5 hand size, 7 Joker slots; Card Sharp + Joker                                                                                    |
| 18 | `c_golden_needle_1`  | Golden Needle     | Discards cost $1; 1 hand, 6 discards; start with $10 + Credit Card                                                                            |
| 19 | `c_cruelty_1`        | Cruelty           | Small and Big Blinds give no reward money; 3 Joker slots                                                                                      |
| 20 | `c_jokerless_1`      | Jokerless         | Jokers never appear in shop; 0 Joker slots                                                                                                    |

"Pinned" is a challenge-only Joker quality that a normal run cannot grant: the Pinned Joker always occupies the leftmost Joker slot and cannot be moved out of it.
