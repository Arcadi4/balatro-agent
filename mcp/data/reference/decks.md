# Balatro Decks Reference

Each deck's `key` is the value to pass as the `deck` argument to `balatro_new_game`. Wiki links point to the full article for each deck.

| key | Name | Effect | Wiki |
|-----|------|--------|------|
| `b_red` | Red Deck | +1 discard every round | https://balatrowiki.org/w/Red_Deck |
| `b_blue` | Blue Deck | +1 hand every round | https://balatrowiki.org/w/Blue_Deck |
| `b_yellow` | Yellow Deck | Start with extra $10 | https://balatrowiki.org/w/Yellow_Deck |
| `b_green` | Green Deck | No interest; +$2 per remaining hand and +$1 per remaining discard at end of round | https://balatrowiki.org/w/Green_Deck |
| `b_black` | Black Deck | +1 Joker slot, -1 hand every round | https://balatrowiki.org/w/Black_Deck |
| `b_magic` | Magic Deck | Start with the Crystal Ball voucher and 2 copies of The Fool | https://balatrowiki.org/w/Magic_Deck |
| `b_nebula` | Nebula Deck | Start with the Telescope voucher, -1 consumable slot | https://balatrowiki.org/w/Nebula_Deck |
| `b_ghost` | Ghost Deck | Spectral cards may appear in the shop, start with a Hex card | https://balatrowiki.org/w/Ghost_Deck |
| `b_abandoned` | Abandoned Deck | Start with no Face Cards in the deck | https://balatrowiki.org/w/Abandoned_Deck |
| `b_checkered` | Checkered Deck | Deck contains 26 Spades and 26 Hearts only | https://balatrowiki.org/w/Checkered_Deck |
| `b_zodiac` | Zodiac Deck | Start with Tarot Merchant, Planet Merchant, and Overstock vouchers | https://balatrowiki.org/w/Zodiac_Deck |
| `b_painted` | Painted Deck | +2 hand size, -1 Joker slot | https://balatrowiki.org/w/Painted_Deck |
| `b_anaglyph` | Anaglyph Deck | After defeating each Boss Blind, gain a Double Tag | https://balatrowiki.org/w/Anaglyph_Deck |
| `b_plasma` | Plasma Deck | Balance Chips and Mult when scoring; X2 base Blind size | https://balatrowiki.org/w/Plasma_Deck |
| `b_erratic` | Erratic Deck | All Ranks and Suits in the deck are randomized | https://balatrowiki.org/w/Erratic_Deck |

`b_challenge` is an internal Challenge Deck marker and is not a valid `deck` value for `balatro_new_game`.
