# Balatro Decks Reference

Each `key` below is the value to pass as the `deck` argument to `balatro_new_game`, together with a `stake` (see `balatro://stakes`). Fetch the full wiki article for a deck as `balatro://wiki/<Name>` with underscores for spaces, e.g. `balatro://wiki/Red_Deck`.

| key           | Name           | Effect                                                                            |
| ------------- | -------------- | --------------------------------------------------------------------------------- |
| `b_red`       | Red Deck       | +1 discard every round                                                            |
| `b_blue`      | Blue Deck      | +1 hand every round                                                               |
| `b_yellow`    | Yellow Deck    | Start with extra $10                                                              |
| `b_green`     | Green Deck     | No interest; +$2 per remaining hand and +$1 per remaining discard at end of round |
| `b_black`     | Black Deck     | +1 Joker slot, -1 hand every round                                                |
| `b_magic`     | Magic Deck     | Start with the Crystal Ball voucher and 2 copies of The Fool                      |
| `b_nebula`    | Nebula Deck    | Start with the Telescope voucher, -1 consumable slot                              |
| `b_ghost`     | Ghost Deck     | Spectral cards may appear in the shop, start with a Hex card                      |
| `b_abandoned` | Abandoned Deck | Start with no Face Cards in the deck                                              |
| `b_checkered` | Checkered Deck | Deck contains 26 Spades and 26 Hearts only                                        |
| `b_zodiac`    | Zodiac Deck    | Start with Tarot Merchant, Planet Merchant, and Overstock vouchers                |
| `b_painted`   | Painted Deck   | +2 hand size, -1 Joker slot                                                       |
| `b_anaglyph`  | Anaglyph Deck  | After defeating each Boss Blind, gain a Double Tag                                |
| `b_plasma`     | Plasma Deck    | Balance Chips and Mult when scoring; ×2 base Blind chip target                      |
| `b_erratic`   | Erratic Deck   | All Ranks and Suits in the deck are randomized                                    |
