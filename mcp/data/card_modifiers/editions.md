# Card Editions

4 editions. Playing cards and Jokers can each hold one; a consumable can only ever get Negative, from Perkeo.

| Edition | Playing card | Joker | Consumable |
| ------- | ------------ | ----- | ---------- |
| Foil | +50 Chips when scored | +50 Chips before that Joker's own effect | N/A |
| Holographic | +10 Mult when scored | +10 Mult before that Joker's own effect | N/A |
| Polychrome | ×1.5 Mult when scored | ×1.5 Mult after that Joker's own effect | N/A |
| Negative | N/A | +1 Joker slot | +1 Consumable slot |

Wiki source: https://balatrowiki.org/w/Card_modifiers#Editions
