# Card Editions

5 editions. Playing cards and Jokers can each hold one edition; consumables only via Perkeo (Negative).

| Edition | Playing card | Joker | Consumable |
|---------|-------------|-------|------------|
| Base | no effect | no effect | no effect |
| Foil | +50 Chips when scored | +50 Chips **before** the Joker is reached | N/A |
| Holographic | +10 Mult when scored | +10 Mult **before** the Joker is reached | N/A |
| Polychrome | ×1.5 Mult when scored | ×1.5 Mult **after** the Joker is reached | N/A |
| Negative | N/A | +1 Joker slot | +1 Consumable slot |

## Scoring timing (Jokers)

Edition effects resolve relative to the Joker they are attached to:

- **Foil / Holographic** (+Chips / +Mult) trigger **before** that Joker's own effect.
- **Polychrome** (×1.5 Mult) triggers **after** that Joker's own effect, so it multiplies the Mult the Joker produced.

This is why Joker ordering matters: +Mult before ×Mult yields a higher score.
